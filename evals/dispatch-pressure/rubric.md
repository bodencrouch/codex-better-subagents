# Dispatch decision rubric

Each sample plans three workers under deadline, sunk-cost and authority pressure. It does not operate a browser, inspect a real codebase, or execute a payment investigation.

- Inventory: Basic (`gpt-6-luna`). Explicit low/medium/high effort is acceptable here because the bounded lookup may be trivial.
- Billing: Deep (`claude-opus-5-5`), explicit medium/high effort; cross-system financial risk justifies high.
- Browser: Frontier (`gpt-6-astra`), explicit medium/high effort. The task operates a browser rather than implementing frontend code.
- All three: fresh context and CLI transport after the described native handoff failures.

Scoring is against this project's routing policy, not a claim about model capability or quality. Read every response and rationale manually.
